# PSA Molten

Graphite and warm porcelain, orange light, precise typography and slow open ribbons. The approved visual reference is the PSA design system brief in PSA Library.

## Identity

Use the lowercase `psa.` wordmark in Segoe UI, bold and tightly spaced. The point is the brand orange. Keep the wordmark clear of the ribbons; never enclose it in a contour blob.

## Modes and materials

Dark and Light use the exact roles in identity.json. Glass is a translucent surface with blur and a visible edge; Solid is opaque. Forms and dense tables use Solid. Selected controls use an inverse fill and a checkmark. Orange text uses the link token, which is darker on Light.

## Motion

Slow open ribbons and sparse rising molten points live at the edges. Keep the reading column still and uncluttered. Both modes have ambient motion. Respect reduced motion, pause when hidden, and freeze for print. Use ds-motion-off for a static deck, ds-solid for opaque cards.

## Typography and exchange

Segoe UI Variable / Segoe UI / Arial; Cascadia Code / Consolas for labels. Slide classes and layouts belong to this theme. Its stylesheet and chrome are the visual maintenance points; review page composition when adapting another theme.
